Passo a passo da imersão

8 passos, na ordem certa

Cada passo depende do anterior — por isso a gente faz junto, sem pular nada.

1

PowerShell, Node.js e Git — liberar o PowerShell uma única vez e instalar as duas ferramentas que fazem o Claude Code rodar.

2

Validar a instalação — três comandos no terminal para confirmar que o ambiente está pronto.

3

Conta no GitHub — onde o histórico do seu projeto fica guardado na nuvem.

4

Instalar o Claude Code — um único comando via npm.

5

Conta na Anthropic — criar o acesso que autentica o Claude Code.

6

Primeiro acesso — abrir o claude no terminal e autenticar pelo navegador.

7

VS Code + GitHub — abrir seu projeto no editor, conectá-lo a um repositório e conversar com o Claude ali dentro.

8

Persona profunda — as 30 dimensões — gerar o retrato psicológico completo do seu cliente ideal com uma Skill e guardar tudo no CLAUDE.md, para o Claude Code usar em tudo que criar.

Persona profunda

Conheça seu cliente por dentro: as 30 dimensões da persona

Com o Claude Code funcionando, o primeiro projeto é montar a persona do seu negócio — não um "público de 25 a 40 anos", e sim um retrato psicológico completo: do que ela teme e esconde ao que ela deseja e nunca admite. É esse mapa que depois guia cada texto, post e oferta que a IA criar para você.

Sombras e Medos — 6 dimensões: sombras existenciais, medos fundamentais, ocultos e primordiais, feridas ancestrais e emocionais.

Desejos e Necessidades — 6 dimensões: necessidades primais, fantasias não realizadas, desejos inconfessáveis e nucleares, e buscas infinitas.

Mecanismos e Padrões — 6 dimensões: compensações, mecanismos de defesa, ciclos viciosos, crenças limitantes e prisões invisíveis.

Identidade e Poder — 6 dimensões: questões de identidade, dinâmicas de poder, traumas e inseguranças profissionais, relacionamentos e conflitos internos.

Existência e Transcendência — 6 dimensões: vazios, sombras arquetípicas, feridas da alma, abismos existenciais, paradoxos e tensões primordiais.

Vira ferramenta de trabalho — buyer persona, ICP, mapa de empatia e anti-persona, salvos no CLAUDE.md para o Claude Code usar em tudo que criar.
