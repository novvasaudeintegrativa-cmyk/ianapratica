Guia da Imersão Claude Code

Setup do Claude Code para a Imersão

Esse é o passo a passo que vamos seguir juntos na Imersão Claude Code, ao vivo e online: liberar o PowerShell, instalar o Node.js e o Git, instalar o Claude Code via npm, criar sua conta na Anthropic e deixar tudo pronto dentro do VS Code. Siga na ordem — cada passo depende do anterior.

15 a 20 minutos Nível: iniciante
Esse guia usa um caminho diferente do resto do tutorial Aqui a gente instala o Claude Code via npm e autentica com uma conta do console.anthropic.com. Se você já fez o setup da trilha completa do tutorial, não precisa repetir — esse guia é só para quem está entrando agora, direto pela Imersão Claude Code.
1. PowerShell, Node.js e Git 2. Validar instalação 3. Conta no GitHub 4. Instalar o Claude Code 5. Conta na Anthropic 6. Primeiro acesso 7. VS Code e GitHub
1

Preparar o ambiente

Liberar o PowerShell e instalar o Node.js e o Git

Liberar o Windows PowerShell — por padrão, o Windows bloqueia a execução de scripts e comandos globais do Node/npm. Vamos liberar isso uma única vez, só para o seu usuário, antes de instalar o Node.js e o Git.

  1. Clique no menu Iniciar e digite PowerShell.
  2. Clique com o botão direito no ícone e selecione "Executar como Administrador".
  3. Cole o comando abaixo e pressione Enter:
PowerShell (como Administrador) 
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Digite S (ou Y) para confirmar e feche essa janela do PowerShell — as próximas etapas usam uma janela comum, sem ser Administrador.

Node.js — mecanismo que instala e roda o Claude Code por trás dos panos:

nodejs.org Baixe a versão LTS (22 ou superior recomendada) e mantenha as opções padrão na instalação. ↗

Git — controle de versão, guarda o histórico de tudo que você e o Claude mudam no projeto:

git-scm.com Baixe o instalador para Windows e siga o assistente usando as opções padrão. ↗
2

Checagem

Validar a instalação no terminal

Abra uma nova janela comum do PowerShell (sem ser Administrador) e rode, um de cada vez:

PowerShell 
node -v
npm -v
git --version
Esperado Se todos os três comandos retornarem um número de versão, o ambiente está pronto para o próximo passo.
Pausa — vamos checar a turma Todo mundo rodou os três comandos e viu o número de versão? Quem ficou com erro avisa agora, antes de seguirmos.
3

Cadastro

Criar Conta no GitHub

O GitHub é onde o histórico do seu projeto (gerenciado pelo Git) fica guardado na nuvem, com backup automático — é pra lá que o Claude Code vai enviar o seu código no último passo deste guia.

github.com/signup Página oficial de cadastro do GitHub ↗
  1. Clique no link acima.
  2. Digite seu e-mail, crie uma senha forte e escolha um nome de usuário — ele aparece nos links dos seus projetos (github.com/seu-usuario/...).
  3. Confirme que não é um robô e siga a verificação.
  4. Confirme seu e-mail pelo link que o GitHub enviar.
  5. Quando perguntarem sobre plano, escolha o gratuito ("Free").
Já tem conta no GitHub? Pode pular direto pro próximo passo.
Pausa — vamos checar a turma Todo mundo criou a conta no GitHub e confirmou o e-mail? Quem já tinha conta, pode seguir.
4

Instalação

Instalar o Claude Code via npm

No mesmo terminal, rode o comando abaixo para instalar o Claude Code globalmente no seu sistema:

PowerShell 
npm install -g @anthropic-ai/claude-code
5

Conta

Criar a conta na Anthropic

  1. Acesse o console.anthropic.com.
  2. Crie uma conta de desenvolvedor e realize a validação via SMS.
Pausa — vamos checar a turma Todo mundo criou a conta na Anthropic e passou pela validação por SMS? Só seguimos quando a turma estiver com o acesso pronto.
6

Primeiro acesso

Inicializar e autenticar

No terminal do PowerShell, execute:

PowerShell 
claude
  • O terminal abrirá uma janela no navegador para autenticar com sua conta do Anthropic Console.
  • Após confirmar a permissão, o Claude Code estará ativo.
Pausa — vamos checar a turma O comando claude abriu e autenticou pra todo mundo? Confirme no chat antes de ir pro VS Code.
7

No editor

Utilizando no VS Code e GitHub

  1. Abra a pasta do seu projeto no VS Code.
  2. Abra o terminal integrado (Ctrl + ').
  3. Certifique-se de que o Git está inicializado no projeto:
PowerShell 
git init

Agora crie o repositório que vai receber esse projeto na nuvem:

github.com/new Criar um novo repositório — dê um nome e deixe sem README, sem .gitignore e sem licença (o projeto local já tem os arquivos) ↗

Depois de criar, o GitHub mostra a URL do repositório (algo como https://github.com/seu-usuario/seu-projeto.git). Copie essa URL e conecte o projeto local a ela:

PowerShell 
git remote add origin https://github.com/seu-usuario/seu-projeto.git
git branch -M main
git add .
git commit -m "Primeiro commit"
git push -u origin main
Troque a URL do exemplo pela sua Use exatamente a URL que o GitHub mostrou pro seu repositório — a do exemplo acima não existe.

Na primeira vez que o Git pedir usuário e senha pra enviar código, o GitHub não aceita mais senha normal — ele pede um Personal Access Token:

github.com/settings/tokens/new Gerar um novo Personal Access Token (classic) — marque o escopo "repo" e clique em "Generate token" ↗

Cole seu nome de usuário do GitHub como usuário, e o token gerado (começa com ghp_) no lugar da senha.

Esse token vale como senha O GitHub só mostra o token completo uma vez. Guarde num gerenciador de senhas — nunca dentro do projeto — e se ele vazar em algum lugar, revogue e gere outro na mesma hora.

Com o repositório conectado, digite claude no terminal integrado do VS Code para interagir diretamente com seu código:

PowerShell 
claude
Pronto! Com isso, seu ambiente está configurado, conectado ao GitHub, e você já pode acompanhar o resto da Imersão direto no seu computador.
Pausa — vamos checar a turma Todo mundo com o projeto no VS Code, conectado ao GitHub e com o claude funcionando? Fechamos o setup aqui.
