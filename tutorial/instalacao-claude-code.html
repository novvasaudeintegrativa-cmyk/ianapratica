O Setup Perfeito

Instalar o Claude Code

Antes de criar qualquer projeto, o Claude Code precisa estar instalado e funcionando direito na sua máquina — esse é o passo mais importante, e o mais pulado por quem quer ir rápido demais. Escolha o seu sistema operacional abaixo: o passo a passo muda um pouco de um pra outro, mas o resultado final é o mesmo.

5 a 15 minutos Nível: iniciante

Qual é o seu sistema operacional?

Detectando seu sistema...

1. Instalar o Node 2. Liberar o PowerShell 3. Instalar o Claude Code 4. Configurar o PATH 5. Reiniciar o PowerShell 6. Iniciar e autenticar
1

Pré-requisito

Instalar o Node.js

O Claude Code é instalado e atualizado usando o Node.js, o mecanismo que roda ferramentas de linha de comando modernas por trás dos panos. Se você já tem o Node instalado, pode pular pro Passo 2 — mas confira a versão antes, pra não ter surpresa lá na frente. É só isso aqui:

Verifique primeiro — abra o menu Iniciar, digite "PowerShell", abra e cole o comando abaixo (o Passo 2 explica esse processo com mais calma, se for a primeira vez que você abre um terminal):

PowerShell 
node -v
Se aparecer um número de versão Tipo v20.14.0 — já está pronto. Qualquer versão a partir da v18 funciona bem. Pode pular direto pro Passo 2.
Se aparecer "node não é reconhecido..." Significa que o Node ainda não está instalado nessa máquina. Sem problema — é só seguir os passos abaixo.

Não tem o Node ainda? Instale assim:

nodejs.org Baixar o instalador oficial do Node.js — escolha a versão LTS, para Windows ↗
  1. Clique no link acima e baixe a versão LTS (a recomendada, mais estável) para Windows.
  2. Abra o instalador baixado e siga o assistente clicando em "Next" mantendo as opções padrão — não precisa marcar nada extra.
  3. Ao final, reinicie o computador se o instalador pedir.

This wizard will guide you through the installation of Node.js.
Click Next to continue.

Depois de instalar Abra um terminal novo e rode de novo o comando node -v lá em cima — se aparecer o número da versão, deu tudo certo e pode seguir pro Passo 2.
2

Preparar o terminal

Abrir o PowerShell e liberar a execução de scripts

O Windows tem dois terminais: o antigo Prompt de Comando (cmd) e o PowerShell, mais moderno — é este que vamos usar daqui pra frente. Abra o menu Iniciar, digite "PowerShell" e clique em Windows PowerShell.

powershell

Melhor correspondência

PS
Windows PowerShell
Aplicativo

Simulação de como a tela aparece — troque pelo print real quando tiver.

Por padrão, o Windows bloqueia a execução de scripts .ps1 — uma proteção contra scripts maliciosos. Precisamos liberar isso só para o seu usuário, e só para scripts assinados. Cole o comando abaixo e aperte Enter:

PowerShell 
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Se aparecer uma pergunta de confirmação, digite S (Sim) e aperte Enter.

Atenção Use exatamente RemoteSigned, não Unrestricted. O primeiro libera o necessário mantendo uma camada de segurança; o segundo desliga a proteção por completo — sem necessidade nenhuma pra esse setup.
3

Instalação

Instalar o Claude Code

Com o terminal liberado, cole o comando oficial de instalação e aperte Enter. Ele baixa e roda o instalador direto do domínio da Anthropic — a mesma empresa que desenvolve o Claude.

PowerShell 
irm https://claude.ai/install.ps1 | iex

Esse comando tem duas partes: irm baixa o script de instalação, e iex executa o que foi baixado. Aguarde de 1 a 3 minutos — o terminal fica "trabalhando" enquanto baixa e configura os arquivos.

Windows PowerShell ─▢✕ 
PS C:\Users\voce> irm https://claude.ai/install.ps1 | iex
Baixando o instalador...
Instalando o Claude Code...

✔ Claude Code successfully installed!

PS C:\Users\voce>

Simulação de como a tela aparece — troque pelo print real quando tiver.

Hábito de segurança Só cole e execute comandos irm ... | iex quando você confia 100% na origem — nesse caso, o domínio oficial claude.ai. Esse padrão de comando baixa e roda código automaticamente, então nunca use com links que alguém te mandou sem você conferir de onde vêm.
4

Configuração — o passo mais importante!

Configurar o PATH

O PATH é a "lista de lugares" onde o Windows procura programas quando você digita um comando. Se o Claude Code não estiver nessa lista, o terminal não vai encontrar o comando claude, mesmo com tudo instalado direitinho.

Olhe o final da mensagem que apareceu no Passo 3: normalmente o próprio instalador já avisa se precisa desse passo extra, e mostra a pasta exata onde instalou. Na maioria dos casos, o comando abaixo resolve:

PowerShell 
[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")
Esperado O comando roda sem mostrar nenhuma mensagem — silêncio total é sucesso aqui. Se aparecer um caminho diferente na tela do Passo 3, use aquele caminho no lugar de $env:USERPROFILE\.local\bin.
5

Aplicar a configuração

Reiniciar o PowerShell

O Windows só relê o PATH quando um terminal novo é aberto — a janela atual não enxerga a mudança do Passo 4 sozinha. Feche essa janela do PowerShell e abra uma nova, do zero, do mesmo jeito que fez no Passo 2.

Erro comum Se depois de reabrir o terminal o comando claude continuar "não reconhecido", reinicie o computador — em alguns casos o Windows demora a propagar a variável para todos os programas.
6

Primeiro acesso

Iniciar o Claude Code e autenticar

Com o terminal novo aberto, digite:

PowerShell 
claude

Na primeira vez, o Claude Code vai te guiar por uma configuração rápida:

  1. Escolha o tema do terminal (light ou dark) — só uma preferência visual, dá pra mudar depois.
  2. Escolha a forma de login — a mais simples é "login com o navegador": o Claude Code abre o navegador automaticamente.
  3. Faça login com a sua conta Anthropic (é necessário um plano Claude Pro ou Max para o Claude Code funcionar).
  4. Se o navegador não abrir sozinho, copie o link que aparecer no terminal e cole no navegador manualmente.
  5. Depois de autorizar, volte para o terminal — ele confirma o login sozinho.

Instalação

Instalar o Claude Code

Com o Terminal aberto, cole o comando abaixo e aperte Enter. Ele baixa e roda o instalador oficial direto do domínio da Anthropic.

Terminal 
curl -fsSL https://claude.ai/install.sh | bash

curl baixa o script de instalação e bash executa o que foi baixado — o mesmo princípio do comando usado no Windows, só que com as ferramentas nativas do macOS.

terminal — zsh — 80×24 
voce@MacBook-Pro ~ % curl -fsSL https://claude.ai/install.sh | bash
Baixando o instalador...
Instalando o Claude Code...

✔ Claude Code successfully installed!

3

Configuração — o passo mais importante!

Configurar o PATH

O PATH é a "lista de lugares" onde o macOS procura programas quando você digita um comando. Cole o comando abaixo e aperte Enter pra garantir que o Terminal sempre encontre o claude:

Terminal — zsh (padrão do macOS) 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
Esperado O comando roda sem mostrar nenhuma mensagem — silêncio total é sucesso aqui. Esse comando faz duas coisas: adiciona a linha no arquivo de configuração do seu terminal (~/.zshrc) e já aplica a mudança na sessão atual.
4

Aplicar a configuração

Reiniciar o Terminal

Feche o Terminal por completo com Command + Q e abra um novo pelo Spotlight, do mesmo jeito que fez no Passo 1 — isso garante que a configuração do Passo 3 seja carregada do zero.

Erro comum Fechar só a aba (Command + W) não é suficiente — use Command + Q pra encerrar o aplicativo Terminal inteiro antes de reabrir.

3

Configuração — o passo mais importante!

Configurar o PATH

O PATH é a "lista de lugares" onde o Linux procura programas quando você digita um comando. A maioria das distribuições usa o bash como shell padrão — se for o seu caso, cole o comando abaixo e aperte Enter:

Terminal — bash (padrão na maioria das distros) 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
Usa zsh, fish ou outro shell? Troque ~/.bashrc pelo arquivo de configuração do seu shell — ~/.zshrc pro zsh, ou ~/.config/fish/config.fish pro fish (nesse caso, a sintaxe do comando muda; se não souber qual shell usa, rode echo $SHELL pra descobrir).
Esperado O comando roda sem mostrar nenhuma mensagem — silêncio total é sucesso aqui.
4

Aplicar a configuração

Reiniciar o terminal

Feche a janela do terminal por completo e abra uma nova — isso garante que a configuração do Passo 3 seja carregada do zero.

Erro comum Se depois de reabrir o terminal o comando claude continuar "não encontrado" (command not found), confira se editou o arquivo certo no Passo 3 — esse é o motivo mais comum de erro nessa etapa.
