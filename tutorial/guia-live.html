Guia da Live

Setup do Claude Code para a Live

Esse é o passo a passo que vamos seguir ao vivo: liberar o PowerShell, instalar o Node.js e o Git, instalar o Claude Code via npm, criar sua conta na Anthropic e deixar tudo pronto dentro do VS Code. Siga na ordem — cada passo depende do anterior.

15 a 20 minutos Nível: iniciante
Esse guia usa um caminho diferente do resto do tutorial Aqui a gente instala o Claude Code via npm e autentica com uma conta gratuita do console.anthropic.com (créditos de teste, sem assinatura). Se você já fez o setup da trilha completa da Imersão com conta Pro/Max, não precisa repetir — esse guia é só para quem está entrando agora, direto pela Live.
1. Liberar o PowerShell 2. Node.js e Git 3. Validar instalação 4. Instalar o Claude Code 5. Conta na Anthropic 6. Primeiro acesso 7. VS Code e GitHub
1

Preparar o terminal

Liberar o Windows PowerShell

Por padrão, o Windows bloqueia a execução de scripts e comandos globais do Node/npm. Vamos liberar isso uma única vez, só para o seu usuário.

  1. Clique no menu Iniciar e digite PowerShell.
  2. Clique com o botão direito no ícone e selecione "Executar como Administrador".
  3. Cole o comando abaixo e pressione Enter:
PowerShell (como Administrador) 
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Digite S (ou Y) para confirmar e feche essa janela do PowerShell — as próximas etapas usam uma janela comum, sem ser Administrador.

2

Pré-requisitos

Instalar o Node.js e o Git

Node.js — mecanismo que instala e roda o Claude Code por trás dos panos:

nodejs.org Baixe a versão LTS (22 ou superior recomendada) e mantenha as opções padrão na instalação. ↗

Git — controle de versão, guarda o histórico de tudo que você e o Claude mudam no projeto:

git-scm.com Baixe o instalador para Windows e siga o assistente usando as opções padrão. ↗
3

Checagem

Validar a instalação no terminal

Abra uma nova janela comum do PowerShell (sem ser Administrador) e rode, um de cada vez:

PowerShell 
node -v
npm -v
git --version
Esperado Se todos os três comandos retornarem um número de versão, o ambiente está pronto para o próximo passo.
4

Instalação

Instalar o Claude Code via npm

No mesmo terminal, rode o comando abaixo para instalar o Claude Code globalmente no seu sistema:

PowerShell 
npm install -g @anthropic-ai/claude-code
5

Conta

Criar a conta na Anthropic e obter créditos

  1. Acesse o console.anthropic.com.
  2. Crie uma conta de desenvolvedor e realize a validação via SMS.
  3. Novas contas recebem US$ 5,00 em créditos de teste gratuitos, o que elimina a necessidade de assinar o plano mensal Claude Pro só para começar.
6

Primeiro acesso

Inicializar e autenticar

No terminal do PowerShell, execute:

PowerShell 
claude
  • O terminal abrirá uma janela no navegador para autenticar com sua conta do Anthropic Console.
  • Após confirmar a permissão, o Claude Code estará ativo.
7

No editor

Utilizando no VS Code e GitHub

  1. Abra a pasta do seu projeto no VS Code.
  2. Abra o terminal integrado (Ctrl + ').
  3. Certifique-se de que o Git está inicializado no projeto:
PowerShell 
git init
  1. Digite claude no terminal integrado do VS Code para interagir diretamente com seu código e repositório.
Pronto! Com isso, seu ambiente está configurado e você já pode acompanhar o resto da Live direto no seu computador.
