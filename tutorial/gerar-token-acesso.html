Gerar o Token de Acesso

O Token é a "chave de fenda" que o Claude vai usar pra abrir a porta do Instagram e publicar em seu nome. Diferente do resto do que fizemos até aqui, vale ter cuidado extra: essa chave, se cair em mãos erradas, dá acesso à sua conta.

~5 minutos
1

Graph API Explorer

Gerar o token

developers.facebook.com/tools/explorer Graph API Explorer — gerador oficial de tokens ↗
  1. Clique no link acima.
  2. No campo "App da Meta", selecione o app que você criou na lição anterior.
  3. No campo "Usuário ou Página", selecione "Token do usuário".
  4. Na aba "Permissions", clique no dropdown de permissões e marque só as necessárias (lista abaixo) — não marque tudo.
  5. Clique no botão azul "Generate Access Token".
  6. Autorize no popup que abrir.
  7. Copie o token que aparecer no campo "Token de acesso".
Print sugerido Graph API Explorer com o app e as permissões selecionadas, antes de clicar em "Generate Access Token".
Marque só o que o Instagram precisa Procure e marque estas permissões: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement e business_management. Não marque "selecionar tudo" — dar mais acesso do que o necessário é um risco de segurança desnecessário, e o objetivo aqui é só publicar no Instagram, não gerenciar campanha de anúncio.
O token vale como uma senha — trate como uma Nunca compartilhe esse token, nunca cole ele direto num arquivo que vai pro GitHub, nunca deixe ele escrito dentro do código. Guarde sempre num arquivo .env, e garanta que esse arquivo está listado no .gitignore — assim ele nunca sai da sua máquina sem querer.
Esse token é temporário O token gerado aqui no Explorer costuma durar só cerca de 1 hora — ótimo pra testar agora, mas insuficiente pra um Agente de IA que precisa postar sozinho todo dia. Trocar esse token por um de longa duração é um dos primeiros passos da próxima categoria da trilha, Orquestração de Agentes de IA.
Estrutura completa Conta protegida, Página criada, Gerenciador de Negócios montado, App configurado e Token em mãos. Esse é o mesmo caminho que a gente percorre com cada cliente antes de ligar o Agente de IA — a partir daqui, o Claude já tem o que precisa pra conversar com o Instagram.
Isso libera a próxima lição na trilha — sem marcar, ela fica travada.
