O Setup Perfeito

Instalação no Mac

No macOS o processo é mais curto: o Terminal já vem com tudo que o instalador do Claude Code precisa, então não existe um passo separado de pré-requisito como no Windows. Siga na ordem e em poucos minutos você já está com o Claude Code rodando.

~5 minutos macOS Nível: iniciante
← Anterior Instalação no Windows Próxima Instalação no Linux
1. Abrir o Terminal 2. Instalar o Claude Code 3. Configurar o PATH 4. Reiniciar o Terminal 5. Iniciar e autenticar
1

Preparar o terminal

Abrir o Terminal

Aperte Command + Espaço pra abrir o Spotlight, digite Terminal e aperte Enter. Esse é o app que vamos usar em toda a instalação — nada de instalar programa nenhum pra esse passo, ele já vem no Mac.

2

Instalação

Instalar o Claude Code

Com o Terminal aberto, cole o comando abaixo e aperte Enter. Ele baixa e roda o instalador oficial direto do domínio da Anthropic.

Terminal 
curl -fsSL https://claude.ai/install.sh | bash

curl baixa o script de instalação e bash executa o que foi baixado — o mesmo princípio do comando usado no Windows, só que com as ferramentas nativas do macOS.

terminal — zsh — 80×24 
voce@MacBook-Pro ~ % curl -fsSL https://claude.ai/install.sh | bash
Baixando o instalador...
Instalando o Claude Code...

✔ Claude Code successfully installed!

voce@MacBook-Pro ~ %

Simulação de como a tela aparece — troque pelo print real quando tiver.

Esperado Aguarde de 1 a 3 minutos até aparecer a mensagem Claude Code successfully installed! no terminal.
Hábito de segurança Só cole e execute comandos curl ... | bash quando confia 100% na origem — nesse caso, o domínio oficial claude.ai. Nunca rode esse padrão de comando com links que alguém te mandou sem conferir de onde vêm.
3

Configuração — o passo mais importante!

Configurar o PATH

O PATH é a "lista de lugares" onde o macOS procura programas quando você digita um comando. Cole o comando abaixo e aperte Enter pra garantir que o Terminal sempre encontre o claude:

Terminal — zsh (padrão do macOS) 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
Esperado O comando roda sem mostrar nenhuma mensagem — silêncio total é sucesso aqui. Esse comando faz duas coisas: adiciona a linha no arquivo de configuração do seu terminal (~/.zshrc) e já aplica a mudança na sessão atual.
4

Aplicar a configuração

Reiniciar o Terminal

Feche o Terminal por completo com Command + Q e abra um novo pelo Spotlight, do mesmo jeito que fez no Passo 1 — isso garante que a configuração do Passo 3 seja carregada do zero.

Erro comum Fechar só a aba (Command + W) não é suficiente — use Command + Q pra encerrar o aplicativo Terminal inteiro antes de reabrir.
5

Primeiro acesso

Iniciar o Claude Code e autenticar

No terminal novo, digite:

Terminal 
claude

Na primeira vez, o Claude Code vai te guiar por uma configuração rápida:

  1. Escolha o tema do terminal (light ou dark) — só uma preferência visual, dá pra mudar depois.
  2. Escolha a forma de login — a mais simples é "login com o navegador": o Claude Code abre o navegador automaticamente.
  3. Faça login com a sua conta Anthropic (é necessário um plano Claude Pro ou Max para o Claude Code funcionar).
  4. Se o navegador não abrir sozinho, copie o link que aparecer no terminal e cole no navegador manualmente.
  5. Depois de autorizar, volte para o terminal — ele confirma o login sozinho.
claude.ai/oauth/authorize

Autorizar o Claude Code

Este aplicativo terá acesso à sua conta Claude Pro/Max nesta máquina.

Simulação da tela de autorização que abre no navegador — troque pelo print real quando tiver.

terminal — zsh — 80×24 
✔ Login successful. Welcome back!

voce@MacBook-Pro ~ % claude
>

Simulação de como a tela aparece — troque pelo print real quando tiver.

Esperado Uma mensagem de Login successful seguida do prompt do Claude Code pronto pra receber comandos.

🆘 Se deu erro no Mac:

Terminal — verificar instalação 
test -f ~/.local/bin/claude && echo "INSTALADO" || echo "NAO INSTALADO"
Leia o resultado Se aparecer INSTALADO, o problema é só o PATH — repita o Passo 3 e reinicie o terminal de novo (Passo 4). Se aparecer NAO INSTALADO, volte pro Passo 2 e rode o comando de instalação outra vez.
Usa Mac mais antigo, com bash em vez de zsh? Troque o comando do Passo 3 por este:
Terminal — bash 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bash_profile && source ~/.bash_profile
Setup concluído Claude Code instalado, PATH configurado e login feito. Você já pode abrir o Claude Code em qualquer pasta de projeto digitando claude — é isso que vamos usar na próxima lição.
