O Setup Perfeito

Criar Conta no GitHub

Se o Git é quem registra o histórico do seu projeto, o GitHub é onde esse histórico mora — na nuvem, com backup automático, acessível de qualquer computador. É esse repositório que a página da Imersão promete: "nunca mais perder trabalho ou depender de pen drive".

~5 minutos
← Anterior Instalar o Git Próxima Instalar o Claude Code
Já tem conta no GitHub? Pode pular direto pra próxima lição — Instalação no Windows (ou Mac). O importante é ter uma conta que você acessa e lembra a senha.
1

Cadastro

Criar a conta

github.com/signup Página oficial de cadastro do GitHub ↗
  1. Clique no link acima.
  2. Digite o mesmo e-mail que você configurou no Git, na lição anterior.
  3. Crie uma senha forte.
  4. Escolha um nome de usuário — ele aparece nos links dos seus projetos (github.com/seu-usuario/...), então vale escolher algo simples e profissional, sem espaços ou caracteres estranhos.
  5. Confirme que não é um robô e siga a verificação.
  6. Confirme seu e-mail pelo link que o GitHub enviar.
  7. Quando perguntarem sobre plano, escolha o gratuito ("Free") — é mais do que suficiente pra tudo que vamos fazer aqui.
Print sugerido Formulário de cadastro do GitHub preenchido, antes de confirmar.
Não precisa criar um repositório agora O GitHub vai perguntar se você quer criar um projeto/repositório logo de cara — pode pular essa parte. Isso acontece naturalmente mais pra frente, quando o Claude Code já estiver instalado e você tiver o primeiro projeto pra guardar.
2

Bônus — guarde pra mais pra frente

Gerar um Token de Acesso

Quando o Git tenta enviar (push) código pro GitHub pela primeira vez, o GitHub não aceita mais login com senha — ele pede um Personal Access Token, uma "senha especial" só pra esse tipo de operação. Você não precisa gerar isso agora; a dica é fazer isso só na hora em que o Git pedir, na primeira vez que você (ou o Claude Code) enviar um projeto pro GitHub. Deixamos o passo a passo aqui pra você não precisar procurar depois.

github.com/settings/tokens/new Gerar um novo Personal Access Token (classic) ↗
  1. Clique no link acima (com login feito no GitHub).
  2. Dê um nome pro token, tipo "Meu computador" — só pra você lembrar depois de onde ele é usado.
  3. Escolha uma data de expiração — 90 dias é um bom padrão; tokens sem prazo são um risco de segurança maior se algum dia vazarem.
  4. Marque o escopo repo — é o que permite enviar código pros seus repositórios.
  5. Clique em "Generate token", no final da página.
  6. Copie o token que aparecer — começa com ghp_.
Print sugerido Tela de criação do token com o escopo "repo" marcado, antes de gerar.
Esse token vale como senha — trate como uma O GitHub só mostra o token completo uma vez, nessa tela — se sair sem copiar, precisa gerar outro. Guarde num gerenciador de senhas, nunca num arquivo dentro do projeto (nem mesmo no .env, que é pra chaves que o código usa em tempo de execução — esse token é diferente, é a sua credencial pessoal de acesso). E se ele passar por algum lugar exposto (um chat, um print, um repositório público), revogue e gere outro na mesma hora.
Onde usar esse token Na primeira vez que o terminal pedir usuário e senha pra um git push, cole seu nome de usuário do GitHub como usuário e este token no lugar da senha. Em alguns fluxos (como o que usamos com o Claude Code), o próprio token entra direto no comando de envio — o importante é reconhecer que é isso que está sendo pedido.
