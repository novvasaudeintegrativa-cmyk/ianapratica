CLAUDE.md

Toda conversa nova com o Claude Code começa "do zero" — ele não lembra o que vocês conversaram ontem. O CLAUDE.md resolve isso: é um arquivo de texto na raiz do seu projeto que o Claude Code lê sozinho, automaticamente, no início de cada sessão. É onde você guarda o contexto que não quer ficar repetindo.

~8 minutos

1

Gerando automaticamente

Criar o seu com o comando /init

Você não precisa escrever esse arquivo do zero. Dentro da pasta do seu projeto, com o Claude Code aberto, rode:

No terminal, dentro do Claude Code 
/init

O Claude Code vai examinar os arquivos do projeto — do que se trata, quais ferramentas usa, como está organizado — e escrever um CLAUDE.md inicial sozinho, na raiz da pasta.

Windows PowerShell ─▢✕ 
> /init
Analisando a estrutura do projeto...
✔ CLAUDE.md criado na raiz do projeto.
>

Simulação de como a tela aparece — troque pelo print real quando tiver.

2

Conteúdo

O que costuma valer a pena guardar ali

Depois que o /init gera a base, você pode (e deve) editar o arquivo à mão como qualquer texto — abra ele no VS Code ou peça pro próprio Claude Code editar pra você. Um bom CLAUDE.md costuma ter:

  • Uma frase curta sobre o que é o projeto.
  • Comandos importantes (como rodar, testar, publicar).
  • Convenções que você quer que sejam sempre seguidas (nome de arquivos, estilo de código, idioma dos comentários).
  • Coisas que o Claude nunca deve fazer sem perguntar antes (apagar uma pasta específica, mexer num arquivo de configuração sensível).
CLAUDE.md — exemplo simples 
# Meu Projeto

Site pessoal com galeria de fotos, feito em HTML/CSS puro.

## Comandos
- Abrir localmente: abrir index.html direto no navegador.

## Convenções
- Comentários e nomes de arquivo sempre em português.
- Nunca mexer na pasta /backup sem perguntar antes.
Curto e vivo, não um manual O CLAUDE.md funciona melhor pequeno e atualizado do que grande e esquecido. Vá adicionando uma linha sempre que perceber que está repetindo a mesma instrução em conversas diferentes.
3

Segurança

O que nunca colocar nesse arquivo

O CLAUDE.md normalmente é versionado junto com o resto do projeto no Git — ou seja, se você mandar ele pro GitHub, qualquer pessoa com acesso ao repositório consegue ler o conteúdo.

Nunca coloque senhas, tokens ou chaves de API aqui Isso vale pro Personal Access Token do GitHub que você gerou lá atrás, pro token do Instagram que vem mais na frente, e pra qualquer credencial em geral. Esse tipo de segredo tem seu próprio lugar (um arquivo .env, um gerenciador de senhas) — nunca dentro de um arquivo pensado pra explicar o projeto pra uma IA.
