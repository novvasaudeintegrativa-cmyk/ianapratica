Claude Code no VS Code

Claude Code no VS Code

Até aqui você usou o Claude Code só pelo terminal — e ele continua funcionando exatamente assim, sem nenhuma mudança. Essa lição adiciona uma camada visual por cima: a extensão oficial do Claude Code pro VS Code, que mostra as mudanças de código lado a lado no próprio editor, com botões pra aceitar ou rejeitar cada uma, sem precisar ficar trocando de janela.

~10 minutos
← Anterior Instalar o Claude Code Próxima Domine os comandos
Isso é opcional Se você prefere continuar só no terminal, pode pular direto pra próxima lição — Domine os comandos. O VS Code não substitui o terminal, só adiciona uma forma visual de trabalhar por cima dele.
1

Editor

Instalar o VS Code (se ainda não tiver)

O VS Code é um editor de código gratuito, feito pela Microsoft, e é o mais usado do mundo hoje — se você já tem ele instalado, pode pular pro próximo passo.

code.visualstudio.com/download Baixar o VS Code — Windows, Mac ou Linux ↗
  1. Clique no link acima — ele já detecta seu sistema operacional sozinho.
  2. Baixe e abra o instalador.
  3. Siga o assistente com as opções padrão (não precisa marcar nada especial).
  4. Abra o VS Code depois de instalado, pra confirmar que funcionou.
2

Projeto

Abrir a pasta do seu projeto

O Claude Code (tanto no terminal quanto no VS Code) sempre trabalha "dentro" de uma pasta de projeto — é ela que define o que ele enxerga e onde ele pode mexer. No VS Code, abra Arquivo → Abrir Pasta (ou File → Open Folder, se o menu estiver em inglês) e escolha a pasta onde você quer trabalhar. Se ainda não tem nenhuma, pode criar uma pasta nova vazia — o Claude Code te ajuda a preencher ela depois.

3

Instalação

Ativar a extensão a partir do terminal

O jeito mais simples de instalar a extensão não é procurando ela na loja do VS Code — é abrindo o terminal integrado (o mesmo terminal que você já usou nas lições anteriores, só que agora dentro do editor) e rodando o comando que você já conhece. O próprio Claude Code detecta que está rodando dentro do VS Code e oferece pra instalar a extensão sozinho.

  1. No VS Code, abra o terminal integrado: menu Terminal → Novo Terminal (ou o atalho Ctrl+` no Windows/Linux, Cmd+` no Mac).
  2. Dentro desse terminal, digite claude e pressione Enter — igual você já fez na lição de instalação.
  3. Quando aparecer a pergunta sobre instalar a extensão do VS Code, responda que sim.
  4. Reinicie o VS Code (feche e abra de novo) pra extensão ativar por completo.

4

Como usar

Aceitar ou rejeitar mudanças direto no editor

Com a extensão ativa, sempre que o Claude Code mudar um arquivo que está aberto no editor, você vê as linhas removidas e adicionadas destacadas diretamente ali — sem precisar abrir um "diff" separado. Cada bloco de mudança vem com um jeito de aceitar ou desfazer só aquele trecho, então você não precisa engolir a resposta inteira de uma vez.

Linha vermelha riscada = removida pelo Claude. Linha verde = adicionada. Simulação — troque pelo print real quando tiver.

Dois atalhos valem a pena decorar:

  1. Ctrl+Esc no Windows/Linux ou Cmd+Esc no Mac — abre ou foca o painel do Claude Code a qualquer momento, de dentro de qualquer arquivo.
  2. Selecionar um trecho de código e perguntar sobre aquele trecho específico — a extensão manda a seleção junto da sua pergunta, então o Claude já sabe exatamente do que você está falando.
Terminal e VS Code trabalham juntos, não competem Você pode continuar usando o comando claude no terminal exatamente como antes — a extensão só acrescenta uma camada visual por cima. Use o que for mais confortável em cada momento; muita gente mistura os dois.
