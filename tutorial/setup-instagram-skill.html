Skill: Setup Instagram Automático

Você já fez o caminho manual em "Conectar ao Instagram" até vincular a Página ao Gerenciador de Negócios. Essa lição ensina um atalho pro que falta: uma Skill do Claude Code, um arquivo de instruções que conduz o restante do processo — criar o App e gerar o Token — numa conversa, testando e salvando tudo sozinho.

De brinde, a skill também funciona como uma checagem automática: antes de seguir, ela pergunta se sua conta é profissional, se a Página está vinculada e se você tem acesso a ela — e avisa pra voltar e corrigir se alguma dessas etapas anteriores não estiver certa. É opcional, mas economiza tempo na próxima vez que precisar repetir esse setup — o seu ou o de um cliente.

~10 minutos Nível: intermediário
O que é uma Skill? É um arquivo de texto (SKILL.md) com instruções escritas em português simples, que ensina o Claude Code a executar uma tarefa específica e complexa sempre do mesmo jeito — passo a passo, com as perguntas certas na ordem certa. Você não precisa saber programar pra criar uma: é basicamente um roteiro.
1

Pré-requisitos

Antes de começar

  • Claude Code já instalado (categoria "O Setup Perfeito", no Dia 1).
  • Sua conta do Instagram já é Profissional (Business ou Creator) — se não for, o próprio Claude te avisa como converter durante a skill.
  • Você tem uma Página do Facebook e acesso ao e-mail/senha dela — se ainda não tiver, faça a lição "Criar a Página do Facebook" primeiro.
2

Instalação

Colocar a skill no lugar certo

As skills do Claude Code ficam guardadas numa pasta .claude/skills/, dentro do projeto onde você quer usá-las. Crie a pasta com o nome da skill e salve o arquivo como SKILL.md lá dentro:

Terminal — dentro do seu projeto 
mkdir -p .claude/skills/setup-instagram

Depois, mova ou cole o conteúdo do arquivo da skill dentro dessa pasta, salvando como .claude/skills/setup-instagram/SKILL.md.

Mais fácil ainda: peça pro próprio Claude Cole o conteúdo da skill na conversa e diga: "Salve isso como uma skill chamada setup-instagram." O Claude Code cria a pasta e o arquivo certo sozinho.
3

Uso

Invocar a skill

Com o Claude Code aberto no seu projeto, é só dizer o que você quer — não precisa decorar comando nenhum. Qualquer uma dessas frases já dispara a skill:

claude 
> quero configurar o instagram

Ola! Vou configurar tudo para voce publicar no Instagram
automaticamente pelo Claude Code. Preciso de uns 10 minutos
do seu tempo e de algumas informacoes que so voce tem acesso.

Antes de comecar, confirma pra mim:
1. Sua conta do Instagram e Profissional (Business ou Creator)?

Simulação de como a conversa começa — troque pelo print real quando tiver.

A partir daí, o Claude conduz sozinho cada etapa:

  1. Confirma os pré-requisitos (conta profissional, Página vinculada, acesso ao Facebook).
  2. Leva você até developers.facebook.com pra criar a conta de desenvolvedor, se ainda não tiver.
  3. Leva você até o Graph API Explorer, ajuda a escolher (ou criar) o App e selecionar sua Página.
  4. Ajuda a adicionar as 3 permissões necessárias (instagram_basic, instagram_content_publish, pages_read_engagement) e gerar o token.
  5. Você cola o token de volta na conversa — o Claude testa na hora e já descobre o ID da sua conta do Instagram.
  6. Salva tudo automaticamente num arquivo .env local (esse sim é o lugar certo pra esse token — é um segredo que o script de publicação usa em tempo de execução).
  7. Instala o script de publicação e testa a conexão ao vivo.
  8. Confirma com um resumo do que foi configurado e como usar dali em diante.
O token continua sendo uma senha Mesmo o Claude testando e salvando por você, a regra não muda: nunca compartilhe esse token com ninguém, e confirme que o arquivo .env está listado no .gitignore do projeto antes de continuar — assim ele nunca vai parar sem querer num repositório no GitHub.
Esse token expira em 1 hora Ótimo pra testar agora, mas insuficiente pra automação de verdade. Quando precisar de um token que dure mais, é só avisar o Claude — ele troca por um token de longa duração em menos de um minuto.
Print sugerido Mensagem final da skill confirmando "Conexão testada com sucesso!" e o resumo do que foi configurado.
Dois caminhos, o mesmo destino Manual (clicando você mesmo, lição por lição) ou por skill (o Claude conduzindo a conversa) — os dois terminam no mesmo lugar: sua conta do Instagram conectada e pronta pra receber posts automáticos. Use o manual pra entender o processo por dentro na primeira vez; use a skill quando quiser repetir isso rápido.
