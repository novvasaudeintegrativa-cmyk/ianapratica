O Setup Perfeito

Instalar o Git

O Git é quem guarda o histórico de tudo que você (e o Claude Code) mudam no seu projeto — cada versão, cada tentativa, cada "antes e depois". É a base que a próxima lição (GitHub) e o próprio Claude Code vão usar o tempo todo, então ele entra primeiro na fila.

~5 minutos Windows ou Mac
1

Windows

Instalar no Windows

git-scm.com/download/win Baixar o instalador oficial do Git para Windows ↗
  1. Clique no link acima — o download começa sozinho.
  2. Abra o instalador e clique em "Next" mantendo todas as opções padrão — não precisa entender nem mudar nenhuma tela do assistente.
  3. No final, clique em "Finish".
Print sugerido Tela inicial do assistente de instalação do Git for Windows.
2

Mac

Instalar no Mac

No Mac, a forma mais simples é deixar o próprio sistema instalar: abra o Terminal (Command + Espaço → "Terminal") e rode o comando abaixo.

Terminal 
git --version
Duas coisas podem acontecer Se um número de versão aparecer, o Git já está instalado — pode pular pro Passo 3. Se em vez disso o macOS abrir uma janela oferecendo instalar as "Command Line Tools", clique em "Instalar" e aguarde — é o próprio sistema instalando o Git (e outras ferramentas de desenvolvedor) pra você, sem precisar baixar nada à parte.
Print sugerido Janela nativa do macOS oferecendo instalar as "Command Line Tools".
3

Configuração — vale pros dois sistemas

Dizer ao Git quem é você

Antes de usar o Git de verdade, ele precisa saber seu nome e e-mail — essa informação fica registrada em cada alteração salva no projeto. Abra o terminal (PowerShell no Windows, Terminal no Mac) e rode, um de cada vez:

Terminal ou PowerShell 
git config --global user.name "Seu Nome"
Terminal ou PowerShell 
git config --global user.email "seu@email.com"
Substitua antes de colar Troque "Seu Nome" pelo seu nome de verdade e seu@email.com pelo e-mail que você vai usar no GitHub, na próxima lição — o ideal é que sejam o mesmo e-mail, pra tudo ficar conectado.
Esperado Os dois comandos rodam em silêncio, sem nenhuma mensagem — é assim mesmo que o Git confirma que salvou a configuração. É um ajuste único: nunca mais precisa repetir isso nessa máquina.
Isso libera a próxima lição na trilha — sem marcar, ela fica travada.
