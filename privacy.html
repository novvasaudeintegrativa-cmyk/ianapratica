Política de Privacidade

Última atualização: agosto de 2026

Esta política descreve como o app "IA na Prática — Automação" usa dados ao se conectar com contas de redes sociais (Instagram e TikTok) em nome do próprio usuário que autoriza a conexão.

O que o app faz

Este é um app de uso pessoal/próprio, que conecta via OAuth à conta de redes sociais do próprio usuário que faz a autorização, com a finalidade de:

  • Publicar posts, imagens e vídeos diretamente na conta autorizada, a pedido do próprio usuário.
  • Consultar informações básicas de perfil (nome de usuário, avatar) necessárias pra confirmar qual conta está conectada.

Quais dados são acessados

  • Tokens de acesso (access token / refresh token) fornecidos pela própria plataforma (Meta/TikTok) após a autorização do usuário — usados só pra fazer as chamadas de API autorizadas.
  • Informações básicas de perfil público da conta conectada.
  • Conteúdo (texto, imagem, vídeo) que o próprio usuário pediu pra ser publicado.

Onde os dados ficam guardados

Tokens de acesso ficam salvos localmente, num arquivo de ambiente (.env) no computador do próprio usuário — nunca em servidor de terceiros, nunca compartilhado, nunca comitado em repositório público.

Compartilhamento com terceiros

Nenhum dado é vendido, compartilhado ou usado para fins de publicidade. O único uso é a publicação de conteúdo autorizada pelo próprio dono da conta, nas plataformas que ele mesmo conectou.
