# TikTok

Pasta pra vídeos de TikTok, separada do resto do projeto de propósito.

**Fora do squad da Imersão "IA na Prática":** essa pasta é conteúdo meu,
avulso — o Maestro, o Social Media, o Copywriter, o Designer e o
`setup-instagram` (tudo que é ensinado na Imersão) continuam cobrindo só
Instagram. Nenhum agente/skill do curso deve ler, escrever ou saber que
essa pasta existe. Se um dia TikTok entrar na Imersão de verdade, isso é
decisão própria — não puxar essa pasta pra dentro do squad sem combinar
antes.

## Estrutura (sugerida, mesmo padrão do `Instagram/`)

```
TikTok/
  V01/
    video.mp4
    legenda.md
  V02/
    ...
```

`V` de vídeo — cada pasta numerada é uma postagem, com o vídeo final e a
legenda/descrição que vai junto.
